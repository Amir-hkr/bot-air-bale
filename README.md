# 🌍 Air Quality Bot with n8n

A smart Air Quality Bot built with **n8n** that provides real-time air pollution and air quality information through **Bale Messenger**. The workflow retrieves live environmental data from an external API and delivers fast, accurate results for any location.

## ✨ Features

* 🌍 Air quality lookup by city
* 🌫️ Real-time AQI (Air Quality Index)
* 💨 Pollution level and environmental data
* 🤖 Bale Messenger integration
* ⚡ Fully automated n8n workflow
* 🌐 API-powered live data
* 🛠️ Easy to import and customize

## 🛠️ Technologies

* n8n
* JavaScript
* HTTP Request
* REST API
* Air Quality API
* Bale Bot API

## 🚀 Setup

1. Import the workflow into n8n.
2. Replace `<YOUR_BALE_BOT_TOKEN>` with your own Bale Bot token.
3. Configure your Air Quality API credentials.
4. Activate the workflow and start receiving live air quality updates.
